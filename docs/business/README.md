# Business Documentation

Business-facing documentation for the **Equity-Aware Geospatial AI Planner**, a decision-support tool for planning hospital locations and bed capacity across the six districts (Landkreise) of Saarland, Germany.

These documents are for non-technical stakeholders: health ministry planners, hospital operators, funders, and project reviewers. For technical setup, see the [project README](../../README.md) and the module READMEs under `src/`.

| Document | Purpose | Audience |
|---|---|---|
| [Executive Summary](executive-summary.md) | One-page overview of the problem, solution, and headline results | Decision makers |
| [Business Case](business-case.md) | Problem statement, value proposition, stakeholders, use cases | Sponsors, partners |
| [Solution Overview](solution-overview.md) | How the planner works, inputs/outputs, and the policy levers it exposes | Planners, analysts |
| [Results & KPIs](results-and-kpis.md) | Scenario comparison, KPI definitions, measured outcomes | Planners, reviewers |
| [Data & Assumptions](data-and-assumptions.md) | Data sources, modelling assumptions, known limitations | Analysts, auditors |
| [Risks & Roadmap](risks-and-roadmap.md) | Risks, mitigations, open questions, next steps | Sponsors, project team |

All figures in these documents come from the artifacts committed in this repository (`src/experiments/results/` and `src/evaluation/data/processed/`), based on 2021 reference data.
